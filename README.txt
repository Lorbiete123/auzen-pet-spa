AUZEN PET SPA

Arquivos:
- index.html: apresentação do Auzen Pet Spa e dos serviços
- style.css: estilos e layout responsivo
- script.js: navegação móvel e ano do rodapé
- img/auzen-gallery/: fotos do mural de pets, com links para as publicações originais

Como abrir:
1. Abra a pasta do projeto no VS Code.
2. Abra index.html com a extensão Live Server ou diretamente no navegador.

Serviços apresentados:
- Banho relaxante
- Tosa cuidadosa
- Cromoterapia
- Massagem relaxante

As chamadas de agendamento direcionam para a seção de contato. Para receber solicitações reais, adicione os canais oficiais de atendimento ou integre um sistema de agendamento.

O mural usa fotos enviadas pelas publicações indicadas do Instagram da Auzen. A faixa passa da direita para a esquerda, pausa ao passar o mouse ou focar uma foto e respeita a preferência do dispositivo por movimento reduzido.
